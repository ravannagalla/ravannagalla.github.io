Learning Track

Cybersecurity Learning

A focused learning path for identity, access security, zero trust, and secure platform engineering. These concepts are essential for building resilient enterprise systems in fintech and cloud-native environments.

IAM Fundamentals

Authentication, authorization, federation, OAuth2, OIDC, RBAC, ABAC, and policy-driven access control.

Zero Trust

Continuous verification, least privilege, segmentation, device trust, and identity-centric security design.

Azure Security

Azure AD / Entra ID, Key Vault, managed identities, RBAC, Defender, and secure Kubernetes patterns.

Cloud Security

Threat modeling, secure deployment pipelines, network security, secrets management, and observability.

Application Security

OWASP, secure coding practices, session management, API gateways, and web app risk reduction.

Incident Response

Detection engineering, logging, alert triage, forensics, and resilience planning for cyber events.
